Privacy Policy

Last updated: 26 November 2026

This Privacy Policy explains how RG GAMER BOY FF handles information when you use our Google sign-in page and main gaming website. It describes the features currently implemented in these pages. We may update this policy if our website or data practices change.

1. About RG GAMER BOY FF

RG GAMER BOY FF is an independent gaming information website. The main website provides game information, descriptions, platform and version details, guides, and links to external websites and download destinations.

The main gaming website does not itself provide a registration form, payment service, or Firebase login form. Google sign-in is handled separately through our associated sign-in page.

Browsing the website is free. We do not display advertisements on our website.

2. Google Sign-In and Account Information

Our separate sign-in page uses Google Sign-In through Firebase Authentication. When you choose to sign in with Google, Google and Firebase process the authentication required to verify your account.

Depending on the information made available by Google, our sign-in system may receive:

  • Firebase User ID
  • Display name
  • Email address
  • Profile photo URL
  • Authentication provider information

We do not receive or store your Google account password. Google handles your Google account authentication under Google's own privacy and security policies.

3. Firebase Realtime Database

After successful Google sign-in, our sign-in page saves a basic account profile in Firebase Realtime Database under the corresponding Firebase User ID.

The profile information used by the current implementation includes:

  • Firebase User ID
  • Sign-in provider
  • Display name, when available
  • Email address, when available
  • Profile photo URL, when available
  • Selected region
  • Selected country
  • Last sign-in timestamp

This information is used to identify the signed-in account, maintain its basic profile, and support the sign-in experience.

Firebase Authentication and Firebase Realtime Database are third-party services provided by Google. Their handling of information is also subject to Google's and Firebase's applicable terms and privacy documentation.

4. Region, Country and Connection Information

The sign-in page allows visitors to select a region and country. The selected region and country are stored in the browser's local storage and are also included in the Firebase account profile after successful sign-in.

The sign-in page periodically sends requests to our Firebase Realtime Database endpoint to display a connection response-time measurement. These requests are used to calculate the displayed database ping and are not intended to retrieve account profile information.

The displayed internet speed is an estimate obtained from the browser's Network Information API when that API is supported. It is not a full internet speed test.

The selected country is a choice made by the visitor. It should not be treated as verified physical location information.

5. Browser Storage and Session Information

Our pages use browser storage for limited website functions:

  • Local Storage: Remembers acceptance of the displayed Privacy Policy and Terms of Service and saves the selected region and country on the sign-in page.
  • Session Storage: Used for a temporary one-time handoff between the sign-in page and the main website.
  • Firebase Authentication Persistence: The sign-in page uses browser-local authentication persistence so that a returning signed-in user may remain authenticated until they sign out or the session is otherwise cleared or invalidated.

You can manage or clear browser storage through your browser settings. Clearing it may affect saved preferences or the sign-in experience.

6. hCaptcha Verification

Some external-link actions on the main website use hCaptcha to help distinguish people from automated traffic.

When hCaptcha loads, its provider may process technical, browser, device, and interaction information to perform verification. This processing is handled by hCaptcha under its own policies.

For more information, read the hCaptcha Privacy Policy and hCaptcha Terms.

7. External Images, Fonts and Website Services

Some website resources are loaded from external providers. These include Google Fonts, externally hosted images, hCaptcha, Firebase, and other services used by linked destinations.

When your browser requests resources from an external provider, that provider may receive technical information such as your IP address, browser information, and request details. We do not control the data practices or retention policies of those providers.

8. External Websites and Downloads

Game, download, redeem, app-store, file-hosting, and community links may take you to third-party websites or services, including Discord and other external destinations.

These services are not controlled by RG GAMER BOY FF. They may collect information, use cookies, display advertisements, request payment, or require their own sign-in process.

Any information you provide directly to an external website is handled under that website's own privacy policy and terms. Please review those policies before using external services or submitting information.

9. Winter Features and Music

The main website includes seasonal winter presentation features such as animated snowfall, decorative interactive snowmen, and optional ambient music.

The ambient soundtrack is loaded as an audio resource by the browser. Music playback may begin automatically where browser rules permit or after a visitor interacts with the page. The music can be paused or resumed using the website's music control.

Interactive snowman sound effects are generated locally in the browser. These presentation features are not intended to collect account details.

10. Hosting and Technical Information

The website is hosted using GitHub Pages. When a visitor opens a website, the hosting provider and related network services may process technical request information such as IP address, browser or device information, requested resources, and request timestamps for delivery, security, and troubleshooting.

We do not control the hosting provider's internal logs or retention practices. Please refer to the applicable provider policies for further information.

11. Cookies and Advertising

RG GAMER BOY FF does not display advertisements on its own website and does not intentionally use advertising cookies in the main static gaming page.

Third-party services such as hCaptcha, Google, Firebase, and external websites may use cookies or similar technologies as part of their services. Their use is governed by their respective policies.

You can manage cookies through your browser settings. Blocking certain cookies or storage features may affect sign-in, verification, or external services.

12. Account Deletion Requests

Visitors who have a Google account connected through our sign-in system may submit an account deletion request using the Account Deletion Request page.

Submitting the request form does not automatically or immediately delete an account. The request must be reviewed, and account ownership may need to be verified before deletion is processed.

Never submit your Google password, one-time verification code, or authentication token through a deletion request form.

13. Data Security and Retention

We use Firebase Authentication and Firebase Realtime Database for the account features described in this policy. Access to stored account information depends on the security rules and configuration applied to the Firebase project.

Account and profile information may remain stored until it is deleted or the relevant service removes it under its applicable retention policies. No website or internet transmission can be guaranteed completely secure.

14. Children and Young Visitors

RG GAMER BOY FF is a general gaming information website. Visitors should check game age ratings and ask a parent or guardian before downloading files or using external services.

Do not share passwords, verification codes, authentication tokens, or sensitive personal information on unknown websites or public community channels.

15. Changes to This Privacy Policy

This policy may be updated when website features, account services, or data practices change. The latest version will be published on this page with an updated date.

16. Contact

For general community questions, visitors may use the Discord link displayed on the relevant game page.

This website does not currently publish a dedicated privacy-request email address. Please do not post private account information or sensitive personal details in public community channels.

This policy describes the website features currently identified in the RG GAMER BOY FF main website and sign-in page. The website owner should review it against the live Firebase security rules, provider settings, and actual deployed behavior before publication.
